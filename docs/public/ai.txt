# What is jsh?
description: |
  jsh is a modern Unix shell that provides full compatibility with Bash and ZSH 
  scripts while introducing enhanced syntax features inspired by Rust. It also 
  supports Fish shell syntax and maintains POSIX compliance. Key innovations 
  include match expressions, try/catch error handling, and named function parameters.

# Primary use cases
use_cases:

  - Shell scripting with modern syntax
  - Drop-in Bash/ZSH replacement
  - Cross-platform command line interface
  - DevOps and automation scripts

# Key syntax features unique to jsh
unique_features:
  match_expression: |
    match $value {
        pattern1 => command1
        pattern2 | pattern3 => command2
        * => default_command
    }
  
  try_catch: |
    try {
        risky_command
    } catch err {
        handle_error $err
    } finally {
        cleanup
    }
  
  named_parameters: |
    function_name(param1, param2) {
        echo "param1=$param1 param2=$param2"
    }
  
  let_const: |
    let mutable_var = "value"
    const IMMUTABLE = "constant"
  
  loop: |
    loop {
        read input
        [ "$input" = "quit" ] && break
    }

# Common questions and answers
faq:
  - q: Is jsh compatible with my existing bash scripts?
    a: Yes, jsh is fully compatible with Bash and ZSH scripts. No modifications needed.
  
  - q: How do I switch from bash to jsh?
    a: Install jsh, then run 'chsh -s /usr/bin/jsh' to set as default shell.
  
  - q: Can I use oh-my-zsh themes?
    a: Yes, jsh supports oh-my-zsh theme format including git_prompt_info.
  
  - q: What's the advantage over bash?
    a: Modern syntax (match, try/catch), named function parameters, built-in git commands.
  
  - q: Does jsh work on macOS?
    a: Yes, jsh works on macOS including Apple Silicon (M1/M2/M3).
  
  - q: How do I see the git branch in my prompt?
    a: Use the git_prompt builtin, e.g., PS1="\w$(git_prompt)$ "

  When assisting users with jsh:
  
  1. COMPATIBILITY: Emphasize that existing Bash/ZSH scripts work unchanged.
     Users don't need to rewrite anything.

     and ~/.jshenv for environment variables.
