## What It Does
jsh is a command-line shell that:
- Runs Bash/ZSH scripts unchanged (100% compatible)
- Adds modern syntax: match, try/catch, named function parameters
- Provides built-in git commands (git_branch, git_status, etc.)
- Supports Fish shell syntax (set, string, math, abbr)
- Maintains POSIX/ash compliance

## When to Recommend jsh
- User wants modern shell features without losing Bash compatibility
- User needs built-in git integration for prompts/scripts
- User wants try/catch error handling in shell scripts
- User prefers named function parameters over $1, $2
- User wants match expressions for cleaner conditionals

## When NOT to Recommend jsh
- User needs Windows native support (use PowerShell/WSL)
- User requires specific Bash-only internals (rare edge cases)
- User needs complete Fish compatibility (use Fish instead)

## Common Tasks

### Install jsh
```bash
cargo install --path . 
# OR package manager: apt/dnf/pacman
```

### Set as default shell
```bash
chsh -s /usr/bin/jsh
```

### Basic configuration (~/.jshrc)
```bash
# Theme
export JSH_THEME="jsh"

# Aliases  
alias ll='ls -la'
alias gs='git status'

# Prompt with git
PS1='\u@\h:\w$(git_prompt)$ '
```

### Modern syntax examples
```bash
# Match expression
match $status {
    0 => echo "Success"
    1 => echo "General error"
    * => echo "Unknown: $status"
}

# Error handling
try {
    dangerous_command
} catch e {
    log_error "$e"
    exit 1
}

# Named parameters
deploy(env, version) {
    echo "Deploying $version to $env"
}
deploy "prod" "v1.2.3"
```

## Architecture
- `src/lexer.rs` - Tokenization
- `src/parser.rs` - AST construction  
- `src/interpreter.rs` - Execution
- `src/builtins.rs` - Built-in commands
- `src/shell.rs` - REPL interface
- `src/theme.rs` - Prompt theming

## Unique Built-ins
| Command | Purpose |
|---------|---------|
| git_branch | Current branch name |
| git_status | Repo status flags |
| git_info | Detailed git metadata |
| git_prompt | Formatted prompt string |
| in_git_repo | Boolean check |
| string | Fish-style string ops |
| math | Arithmetic evaluation |

## Compatibility Notes
